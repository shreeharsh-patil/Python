# Contributing

Thanks for contributing to this Python learning repository.

## Guidelines

- Keep examples focused on one Python concept at a time.
- Prefer clear, beginner-friendly names and comments.
- Do not introduce external dependencies unless an example specifically needs one.
- Run any modified script with the appropriate Python 3 interpreter before opening a pull request.
- Keep unrelated changes in separate pull requests so they are easy to review.

## Pull requests

Please include a short summary of what the example demonstrates and, when relevant, the command used to verify it.
